# 블랙아웃 (BLACKOUT) — 재난 안전 대응체계

재난이 나면 처음 72시간은 스스로 버텨야 한다는 전제에서 출발한 재난 대응 웹페이지입니다.
**전기·통신이 끊기면 이 페이지도 열리지 않는다**는 점을 설계의 중심에 두고, 모든 화면이 PDF로 떨어지게 만들었습니다.

외부 라이브러리 없음 · 네트워크 호출 없음 · 빌드 도구 없음. `index.html`을 브라우저로 열면 바로 작동합니다.

---

## 파일 구조 (공유·분업용)

| 파일 | 역할 | 누가 고치나 |
|---|---|---|
| `index.html` | 화면 구조(마크업) + 제작 가이드 10종 본문 + SVG 도해 3장 | 문서·콘텐츠 담당 |
| `style.css` | 디자인 토큰, 레이아웃, **인쇄/PDF 레이아웃** | 디자인 담당 |
| `data.js` | 재난 수칙 · 재료 · 레시피 · 품목 · 가격 · 진단 문항 **전부** | 기획·콘텐츠 담당 |
| `app.js` | 화면 로직(탭, 진단 채점, 재료 매칭, 장바구니, PDF 범위) | 개발 담당 |

데이터와 로직을 분리해 두었기 때문에 **문구·품목·가격·수칙 수정은 `data.js` 한 파일만** 건드리면 됩니다.

### data.js 안에서 고칠 곳

| 변수 | 내용 |
|---|---|
| `RESPONSE` | 재난 대응 4단계 (인지 → 차단 → 보호 → 자립) |
| `PRINCIPLES` | 모든 재난 공통 원칙 5가지 |
| `DISASTERS` | 재난 5종 × (지금 / 5분 후 / 1시간 후 수칙 + 금지사항). 수칙에 `item`을 적으면 그 자리에 [키트에 담기] 버튼이, `make`를 적으면 [직접 만들기] 버튼이 생깁니다 |
| `MATCATS` / `PRESET` | 집 재료 35품목 / "일반 가정 기본값" 체크 목록 |
| `RECIPES` | 제작물 11종의 필요 재료. `any: [...]`는 "이 중 하나라도 있으면 충족" |
| `ITEMS` / `KITS` | 판매 품목 30종(예상가) / 상황별 세트 5종 |
| `QUIZ` / `AXFIX` / `TYPES` | 진단 10문항 / 약한 축별 추천 / 결과 유형 |

새 재난을 추가하려면 `DISASTERS`에 한 덩어리를 붙이면 됩니다. 탭·카드·대피 카드·추천 키트가 자동으로 따라옵니다.

## 화면 구성

```
00 대응체계     재난 대응 4단계 + 공통 원칙 5 + "어떤 재난이 걱정되나요?" 재난 선택
01 대비력 진단  10문항 → 물·식량/전력·조명/정보·연락/손기술 4축 → 유형 + 부족한 것만 추천
02 행동수칙     지금 / 5분 후 / 1시간 후 3단 카드 + 절대 금지 + 수칙별 [키트에 담기]
03 집 재료 제작 보유 재료 체크 → 제작 가능 여부 실시간 계산 + 제작 가이드 10종
04 내 키트      상황별 세트 5종 + 개별 품목 30종 + 장바구니(예상 합계)
05 오프라인 꾸러미  PDF 5종 저장 + 비상 대피 카드 작성/A4 출력
```

## PDF 저장이 동작하는 방식

`app.js`의 `printMode(mode)` 하나로 처리합니다.

1. `document.body.dataset.print = mode` 를 설정
2. `style.css`의 `@media print` 가 `body[data-print="..."]` 로 **인쇄할 범위만 남김**
3. `window.print()` → 사용자가 인쇄 창에서 **대상을 "PDF로 저장"** 선택

| mode | 범위 |
|---|---|
| `all` | 전체 매뉴얼 (진단 문항·조작 UI 제외) |
| `action` | 선택한 재난의 행동수칙 1장 |
| `guides` | 제작 가이드 10종 (닫힌 아코디언도 자동으로 펼친 뒤 원복) |
| `kit` | 담아 둔 키트 구매 목록 |
| `card` | 비상 대피 카드 A4 1장 |

버튼에 `data-pdf="모드"` 만 달면 자동으로 연결됩니다 (`app.js` 하단에서 일괄 바인딩).

> jsPDF 같은 라이브러리를 쓰지 않은 이유: 한글 폰트를 PDF에 심어야 해서 용량이 수 MB 늘고 글자가 깨질 위험이 큽니다.
> 브라우저 인쇄 엔진을 쓰면 한글이 그대로 나오고 레이아웃을 CSS로 통제할 수 있습니다.
> 단, **웹에 게시된 상태에서는 보안 샌드박스가 자동 다운로드를 막기 때문에** 인쇄 창을 경유하는 이 방식이 유일하게 확실한 경로입니다.

## 저장되는 데이터

진단 답변, 보유 재료, 장바구니, 대피 카드 입력값은 `localStorage['blackout.v1']` 에만 저장됩니다.
서버 전송 없음, 외부 API 없음. 브라우저를 바꾸면 초기화됩니다.

## 면책

해커톤 시연용 교육 자료입니다. 품목 예상가는 참고값이고 결제 기능은 없습니다.
실제 재난 시에는 119 신고와 공식 지침(국민재난안전포털·재난문자)이 항상 우선합니다.
자가 제작물은 정식 장비의 대체품이 아니며, 화재·전기·의료 항목은 각 가이드의 안전 경고를 함께 읽어야 합니다.
