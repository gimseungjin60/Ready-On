# BLACK-OUT : MARS — 화성 거주구 재난 대비 (mars 브랜치)

> 이 브랜치는 서비스 주제를 **화성 정착 시대의 거주자**로 바꾼 버전입니다. `main` 브랜치(지구판 BLACK-OUT)는 그대로 있습니다.

- **원칙**: 공상과학보다 '근거 있는 미래'. 수치와 절차는 NASA·국제우주정거장(ISS) 공개 자료를 참고했고, 정착지·시설·가격은 시연용 가상 설정임을 화면에 표시합니다.
- **화면**: 홈(실제 화성 사진 + 바람에 날리는 먼지 + 거주구 상태 HUD) → 소개(통신 지연 3~22분·기압 0.6%·먼지폭풍) → 생존력 테스트(거주 형태·차폐·비상 산소·구조 로봇 등 10문항) → 비상 행동수칙(기압 손실·태양폭풍·거주구 화재·먼지폭풍·생명유지 고장 × 지금/5분 후/1시간 후) → 거주구 키트(일러스트 8종) → GALE 정착지 지도 + 맞춤 키트 계산 → 비상 카드(A4 2장) / 거주구 DIY(`make.html`).
- **키트 계산**: 1인 1솔 산소 0.84kg·물 3L·식량 1.8kg(NASA 생명유지 기준 문서 대표값 참고), 정착지 거리별 3/7/14솔·궤도 30솔, 소모품만 기간 비례·공동 장비 고정·재난 중복 시 큰 값 하나.
- **이미지**: 사진은 NASA/JPL-Caltech 퍼블릭 도메인(`assets/mars/CREDITS.md`). 상품 일러스트 8종(`assets/mars/kit-*.svg`)은 직접 제작했습니다. 지도 배경은 게일 크레이터 궤도 사진이며 축척은 시연용 가정입니다.
- **거주구 DIY 근거**: 2018년 ISS 누출 테이프 수리, 1970년 아폴로 13호 CO₂ 필터 개조, 물의 방사선 차폐 원리 등. 출처를 확인하지 못한 항목은 '일반 요령'으로 구분합니다.

# BLACK-OUT — AI 재난 대비 및 맞춤형 안전키트 플랫폼 (MVP)

> 재난이 닥치기 전, 준비를 켜다.

재난 대비력 테스트 → 유형 진단 → 재난별 행동수칙 → 맞춤 안전키트·장바구니 → 대피소 확인 → 오프라인 대피 카드 출력까지 이어지는 정적 웹 MVP입니다. HTML/CSS/Vanilla JS만 사용하며 빌드 과정이 없습니다.

## 실행 방법

지도 타일(OpenStreetMap)과 주소 검색은 `file://`로 열면 Referer가 없어 차단될 수 있으므로 **로컬 서버로 실행**하세요.

```bash
cd readyon
python -m http.server 5500      # 또는: npx serve .
```

브라우저에서 http://127.0.0.1:5500 접속.
VS Code의 Live Server 확장을 써도 됩니다.

## 웹 업로드 (실습 호스팅 FTP)

1. 사이트 파일만 `바탕 화면	eam2`로 내보냅니다 (index.html, make.html, css, js, assets, readykit 엔진·대피시설 데이터).
2. `scripts/deploy_ftp.py`(Python ftplib)로 FTP `/www/team2/` 안에만 올립니다. 비밀번호는 실행할 때 환경변수로 넣습니다.

```powershell
$env:FTP_PASS='비밀번호'; python scripts/deploy_ftp.py
```

- `/www/team2`가 없으면 아무것도 만들지 않고 멈추며, 삭제는 하지 않습니다. 다른 조 폴더와 최상위 파일은 건드리지 않습니다.
- index.html이 없거나 .php·.py·.env·key.txt가 섞여 있거나 파일 이름에 한글·띄어쓰기가 있으면 올리지 않습니다.

## 발표 모드 (페이지 넘기기)

긴 스크롤 대신 한 번에 한 화면만 보여 줍니다.

- 상단 메뉴를 눌러 이동합니다. 로고를 누르면 홈으로 돌아갑니다.
- 순서: 홈 → 서비스 소개 → 대비력 테스트 → (나의 결과) → 재난 행동수칙 → 안전키트 → 대피소 찾기 → 우리집 만들기 → 오프라인 대피 카드 → 마무리(대피 카드 화면 오른쪽 아래 '마무리' 링크)

### 위치 지정
현재 위치(동의 후 1회, 오차·측정 시각 표시, 오차 1km 이상이면 수동 확인 안내) · 주소/장소 검색(Nominatim) · 지도 클릭 · 핀 끌기 · 위·경도 입력 · 시·군·구 선택(상세 위치 없이). 처음 화면의 서울시청은 "예시 기준점 · 내 위치 아님"으로 표시합니다. 권한 거부·시간 초과·검색 실패 시 다른 방법으로 계속 계산할 수 있습니다.

### 계산 규칙
- **비축 기간**(엔진 정책 `2026-11-05.v1`, 서비스 계획 가정): 시·구 3일 / 군 7일 / 울릉군 14일 / 지역 자료 없음 임시 7일. "기간" 선택으로 7·14·30일 이상으로 늘릴 수 있고(줄이지는 않음), 늘린 사실을 표시합니다.
- **물** 1인 하루 4L(미국 CDC 1갤런≈3.8L 비축 안내를 올림), **식량** 1인 하루 2,000kcal ÷ 4,000kcal/kg = 0.5kg.
- **유형별 계산**: 소모품 = 1인 하루량 × 일수 × 인원 / 개인 장비 = 1인 수량 × 인원 / 기간 장비(건전지·보조배터리) = 일수 기준 개수 × 인원 / **공동 장비(라디오·소화기 등) = 가구당 고정, 기간·인원과 무관**.
- **여러 재난**: 같은 물품은 큰 값 하나만 적용(엔진 `Math.max`). 홍수+태풍을 골라도 우의는 1벌입니다.
- **추가 구매** = max(0, 필요량 − 있어요 입력값), **구매 개수** = ⌈추가 구매 ÷ 포장 단위⌉ (물 2L 병, 식량 500g 팩 등). 구매 개수를 바꾸면 "추천보다 n개 적어요 · xL 부족 / n개 많아요"를 표시합니다.
- 가격·무게는 시연용 가상 값입니다. 재난 발생 확률, 구조 도착 시간, 생존 확률은 계산하지 않습니다.

## 개인정보·안전 원칙

- 테스트 응답, 장바구니, 대피 카드는 브라우저 localStorage에만 저장되며 서버로 보내지 않습니다. 대피 카드는 "이 브라우저에 저장"을 눌렀을 때만 저장됩니다.
- 위치 정보는 자체 동의 다이얼로그 → 브라우저 권한 순서로 요청하고, 거부하면 주소 입력으로 안내합니다.
- 주소 검색 시 검색어만 OpenStreetMap Nominatim으로 전송됩니다.
- 행동수칙은 행정안전부 국민재난안전포털 「국민행동요령」, 소방청 화재 대피 안내(2024 「살펴서 대피」)를 요약했습니다. 공식 지침이 없는 시간 구간은 비워 두고 "관계기관 안내를 따르라"는 안내만 표시합니다(예: 화재 1시간 후).
- 가격은 모두 MVP 시연용 가상 가격이며, 결제는 연동되지 않았습니다(구매하기 → 주문 요약 + 결제 준비 안내).

## 확인한 항목

헤드리스 Chrome(puppeteer-core)으로 다음을 자동 점검했고 콘솔 오류는 0건이었습니다.

- 테스트 10문항 진행·이전/다음, 점수(50/100/0점 케이스)·유형·TOP3·추천 키트
- 행동수칙 탭 전환, 화재 1시간 후 빈 단계 안내, 행동수칙 물품 담기
- 장바구니 담기·수량·삭제·합계, 새로고침 후 장바구니·결과·대피 카드 유지
- 실제 대피시설 8곳 표시, 재난 종류 전환, 목록·마커 연동, 대피 카드 저장, 주소 검색(부산역)
- 대피 카드 입력 이스케이프, A4 PDF 출력(한 장), 대피소 목록 인쇄
- 메뉴·뒤로 가기 화면 전환, 새로고침 시 현재 화면 유지, 화면 전환 후 지도 크기 재계산
- 390px 모바일: 햄버거 메뉴로 이동, 가로 스크롤 없음

## 우리집 재료로 만들기 (`make.html`)

재료 19가지(주방·욕실·청소·생활용품)를 조합대에 최대 3개 올리고 "조합하기"를 누르면, 맞는 조합일 때 생존 용품이 완성되어 "나의 조합 도감"(18가지)에 저장됩니다.

- 아이도 따라 할 수 있게 모두 3단계 이하이며 불과 칼은 쓰지 않습니다. 가위가 필요한 것은 "어른과 함께"로 표시합니다.
- 재료 칸마다 대체 재료를 허용합니다. 예: 구조 요청 깃발 = 수건·헌 옷 **또는** 담요. 틀리면 무엇이 더 필요한지 힌트를 줍니다.
- 만드는 법마다 근거 자료를 표시합니다: 東京都「東京防災」 p.198–199, 일본 내각부 방재 홍보지 71호, 경시청 広報 74호, 구마모토현 방재 교육 지도안, 사이조시 방재 강좌, 국민재난안전포털. 공식 출처를 찾지 못한 것(방수 주머니, 이름표, 골판지 깔개, 반사판)은 "일반 생활 안전 요령"으로 구분합니다.
- 행동수칙 카드의 "집에 있는 재료로 만들기" 링크(`make.html#mask` 등)로 바로 해당 만드는 법을 엽니다.
- 만든 조합법을 모아 A4로 인쇄·PDF 저장할 수 있습니다.
- 도감에서 ✓ 표시한 조합법(최대 4개)이 대피 카드 뒷면에 들어갑니다. 없으면 손으로 적는 빈칸이 들어갑니다.
- 팀원 브랜치 `khg/blackout`의 장점(재료 분류, 대체 재료, 제작 가이드 PDF, 행동수칙 연결, 골판지·반사판·양동이 화장실)을 반영했습니다. 불을 쓰는 캔 램프, 간이 소화기, 자전거 발전기, 소금물 전지, 지혈대처럼 아이에게 위험하거나 효과가 불확실한 항목은 넣지 않았습니다.

## 오프라인 대피 카드 (A4 2장)

- 앞면: 긴급 전화, 나의 정보(혈액형·지병), 대피소와 가족 만남 장소, 비상 연락처, 대피 경로 그리기 칸, 잘라 쓰는 지갑 카드 2장(신용카드 크기 85.6×54mm)
- 뒷면: 재난별 행동 순서, 우리집 재료로 만들기 4개, 비상용품 체크리스트, 메모, 점검한 날
- 미리보기는 실제 A4 크기로 그린 뒤 축소해 보여 주므로 인쇄·PDF와 같습니다. 인쇄 창에서 "PDF로 저장"을 고르면 `BLACKOUT_대피카드_이름.pdf`로 저장됩니다.
- 흑백 프린터로 뽑아도 읽을 수 있게 검정 한 가지 색만 씁니다.
