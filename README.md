# READY : ON — AI 재난 대비 및 맞춤형 안전키트 플랫폼 (MVP)

> 재난이 닥치기 전, 준비를 켜다.

재난 대비력 테스트 → 유형 진단 → 재난별 행동수칙 → 맞춤 안전키트·장바구니 → 대피소 확인 → 오프라인 대피 카드 출력까지 이어지는 정적 웹 MVP입니다. HTML/CSS/Vanilla JS만 사용하며 빌드 과정이 없습니다.

## 실행 방법

지도 타일(OpenStreetMap)과 주소 검색은 `file://`로 열면 Referer가 없어 차단될 수 있으므로 **로컬 서버로 실행**하세요.

```bash
cd readyon
python -m http.server 5500      # 또는: npx serve .
```

브라우저에서 http://127.0.0.1:5500 접속.
VS Code의 Live Server 확장을 써도 됩니다.

## 웹 업로드 (실습 호스팅 FTP)

`scripts/deploy-ftp.ps1`이 사이트에 필요한 파일만 지정한 팀 폴더에 올립니다. 비밀번호는 파일에 저장하지 않고 실행할 때 환경변수로 넣습니다.

```powershell
$env:FTP_PASS='비밀번호'; powershell -ExecutionPolicy Bypass -File scripts\deploy-ftp.ps1 team2
```

- 팀 폴더(team1~team8)가 FTP 최상위나 `www/` 아래에 이미 있을 때만 올리고, 다른 조 폴더와 최상위 `index.html`은 건드리지 않습니다.
- 올린 뒤 주소: `http://educnp.mycafe24.com/team2/`
- "내 위치" 기능은 브라우저 정책상 HTTPS 주소에서만 동작합니다. HTTP로 열면 주소 검색을 사용하세요.

## 발표 모드 (페이지 넘기기)

긴 스크롤 대신 한 번에 한 화면만 보여 줍니다.

- 상단 메뉴를 눌러 이동합니다. 로고를 누르면 홈으로 돌아갑니다.
- 순서: 홈 → 서비스 소개 → 대비력 테스트 → (나의 결과) → 재난 행동수칙 → 안전키트 → 대피소 찾기 → 우리집 만들기 → 오프라인 대피 카드 → 마무리(대피 카드 화면 오른쪽 아래 '마무리' 링크)
- 주소의 `#해시`가 현재 화면이라 새로고침·뒤로 가기도 그대로 동작합니다. 예: `index.html#kit`
- 결과 화면은 테스트를 마친 뒤에만 순서에 포함됩니다.
- 시연 전 초기화: 브라우저 개발자 도구 콘솔에서 `localStorage.clear()` 후 새로고침

## 구조

```
index.html              전체 페이지 (섹션 01~10 + 테스트 모달 + 장바구니 드로어 + 각종 다이얼로그)
css/style.css           디자인 토큰 + 컴포넌트 + 섹션 스타일
css/responsive.css      1280 / 1080(햄버거 전환) / 760 / 420px 분기
css/print.css           A4 인쇄 (대피 카드 / 대피소 목록)
js/storage.js           localStorage 래퍼, 모듈 간 이벤트(RO.emit/RO.on), 토스트, HTML 이스케이프
js/products.js          키트·개별 물품 데이터, 키트 그리드, 결과 기반 추천 정렬
js/disaster.js          재난 5종 × 3단계 행동수칙 데이터와 탭 UI, 오프라인 카드용 핵심 수칙
js/cart.js              장바구니 (담기·수량·삭제·합계·비우기·주문 요약)
js/test.js              10문항 테스트, 점수·유형·부족 TOP3·맞춤 수칙·추천 키트 산출, 결과 섹션
js/shelter.js           전체 화면 지도, 실제 대피시설 조회(readykit 데이터·엔진), 위치 권한, 길찾기, 목록 인쇄
js/recipes.js           우리집 재료로 만들기 (재료 선택 → 만들 수 있는 생존 용품, 만드는 법, 대피 카드 연결)
js/offline-card.js      대피 카드 입력·A4 2장 미리보기(실제 출력과 동일)·저장·PDF 인쇄
js/hero.js              히어로 효과 (불씨·재 파티클 캔버스, 마우스를 따라가는 손전등 불빛)
js/main.js              페이지(뷰) 라우터·키보드 이동·전환 커튼, 헤더/햄버거, 다이얼로그, 등장·카운트업·카드 기울기
assets/images/          사진 (퍼블릭 도메인, 출처는 assets/images/CREDITS.md)
```

모든 모듈은 전역 `window.RO` 네임스페이스에 붙습니다. 백엔드(Spring Boot 등)를 붙일 때는 각 모듈의 데이터 부분만 API 호출로 바꾸면 됩니다.

## 점수 산출 규칙

- Q1~Q3(거주 형태·동거 여부·층수): 점수 없음, 맞춤 수칙·추천에만 사용
- Q4~Q10: 준비됨 2점 / 일부 1점 / 없음 0점 → 14점 만점을 100점으로 환산
- 0–39 AI 없으면 얼음형 · 40–69 아직 준비 중인 생존형 · 70–89 준비된 생존형 · 90–100 생존 마스터형
- 부족 TOP3: 점수가 낮은 문항 순(동점이면 문항 순서)
- 추천 키트: 부족 문항별 가중치 + 프로필 가중치(고층→지진·화재, 저층·단독→침수, 1인 가구→미니 키트, 가족→72시간)의 합 상위 3개

## 대피소 데이터 (팀원 readykit 연동)

대피소 화면은 `readykit/`(sjw/feature 브랜치)의 **행정안전부 국민안전24 안전지도 공개 데이터 스냅샷**(2026-11-05 수집, 민방위 대피소·지진 옥외대피장소·이재민 임시주거시설·무더위쉼터·한파쉼터)을 사용합니다.

- `js/shelter.js`가 `readykit/dist/data/shelters-index.json`을 읽고, 반경 30km에 걸치는 1도 단위 구역 파일만 불러옵니다.
- 가까운 시설 계산(`nearestShelters`)과 시설 유형 정의(`SHELTER_TYPES`)는 `readykit/dist/engine.mjs`를 그대로 불러 씁니다. `.mjs`의 MIME 설정이 없는 서버에서도 동작하도록 파일을 받아 모듈로 불러옵니다.
- 재난 종류 탭(지진·홍수·태풍·화재·전쟁·폭염·한파)에 따라 시설 유형을 바꾸며, 가까운 8곳을 직선거리 순으로 보여 줍니다. 실제 개방 여부와 도보 경로는 알 수 없으므로 화면과 인쇄물에 함께 표시합니다.
- 처음 화면에서는 서울시청(예시 기준점) 주변을 보여 줍니다. 주소 검색(OpenStreetMap Nominatim)과 내 위치(동의 후)로 기준점을 바꿀 수 있습니다.
- 데이터 갱신은 `readykit/scripts/`의 수집·정제 스크립트를 사용합니다. 자세한 내용은 `readykit/README.md`를 보세요.

## 개인정보·안전 원칙

- 테스트 응답, 장바구니, 대피 카드는 브라우저 localStorage에만 저장되며 서버로 보내지 않습니다. 대피 카드는 "이 브라우저에 저장"을 눌렀을 때만 저장됩니다.
- 위치 정보는 자체 동의 다이얼로그 → 브라우저 권한 순서로 요청하고, 거부하면 주소 입력으로 안내합니다.
- 주소 검색 시 검색어만 OpenStreetMap Nominatim으로 전송됩니다.
- 행동수칙은 행정안전부 국민재난안전포털 「국민행동요령」, 소방청 화재 대피 안내(2024 「살펴서 대피」)를 요약했습니다. 공식 지침이 없는 시간 구간은 비워 두고 "관계기관 안내를 따르라"는 안내만 표시합니다(예: 화재 1시간 후).
- 가격은 모두 MVP 시연용 가상 가격이며, 결제는 연동되지 않았습니다(구매하기 → 주문 요약 + 결제 준비 안내).

## 확인한 항목

헤드리스 Chrome(puppeteer-core)으로 다음을 자동 점검했고 콘솔 오류는 0건이었습니다.

- 테스트 10문항 진행·이전/다음, 점수(50/100/0점 케이스)·유형·TOP3·추천 키트
- 행동수칙 탭 전환, 화재 1시간 후 빈 단계 안내, 행동수칙 물품 담기
- 장바구니 담기·수량·삭제·합계, 새로고침 후 장바구니·결과·대피 카드 유지
- 실제 대피시설 8곳 표시, 재난 종류 전환, 목록·마커 연동, 대피 카드 저장, 주소 검색(부산역)
- 대피 카드 입력 이스케이프, A4 PDF 출력(한 장), 대피소 목록 인쇄
- 메뉴·뒤로 가기 화면 전환, 새로고침 시 현재 화면 유지, 화면 전환 후 지도 크기 재계산
- 390px 모바일: 햄버거 메뉴로 이동, 가로 스크롤 없음

## 우리집 재료로 만들기

집에 있는 재료 11가지를 고르면 만들 수 있는 생존 용품 10가지(물병 랜턴, 젖은 수건 마스크, 신문지 보온재·슬리퍼, 비닐 우비, 비상 화장실, 방수 주머니, 비상 이름표, 페트병 비상 식수, 구조 요청 깃발)를 보여 줍니다.

- 아이도 따라 할 수 있게 모두 3단계 이하이며 불과 칼은 쓰지 않습니다. 가위가 필요한 것은 "어른과 함께"로 표시합니다.
- 각 만들기에는 안전 주의 문구가 붙어 있습니다. 비닐 우비는 얼굴을 덮지 않도록, 젖은 수건 마스크는 대피가 먼저라는 점을 강조합니다.
- "대피 카드에 넣기"로 고른 것(최대 4개)이 대피 카드 뒷면에 들어갑니다. 고르지 않으면 지금 만들 수 있는 것과 기본 추천으로 채웁니다.

## 오프라인 대피 카드 (A4 2장)

- 앞면: 긴급 전화, 나의 정보(혈액형·지병), 대피소와 가족 만남 장소, 비상 연락처, 대피 경로 그리기 칸, 잘라 쓰는 지갑 카드 2장(신용카드 크기 85.6×54mm)
- 뒷면: 재난별 행동 순서, 우리집 재료로 만들기 4개, 비상용품 체크리스트, 메모, 점검한 날
- 미리보기는 실제 A4 크기로 그린 뒤 축소해 보여 주므로 인쇄·PDF와 같습니다. 인쇄 창에서 "PDF로 저장"을 고르면 `READY-ON_대피카드_이름.pdf`로 저장됩니다.
- 흑백 프린터로 뽑아도 읽을 수 있게 검정 한 가지 색만 씁니다.
